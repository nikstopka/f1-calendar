# F1 Календарь 2026

Полностью автоматизированный календарь Формулы 1 2026 для iPhone и веб-сайта.

## Возможности

- **23 этапа** — все сессии (FP1, FP2, FP3, Спринт-квалификация, Спринт, Квалификация, Гонка)
- **Время по МСК** (UTC+3)
- **Личный зачёт пилотов** — топ-23 пилота с очками
- **Командный зачёт** — все 11 команд с очками
- **Результаты квалификации** — стартовая решётка для прошедших гонок
- **Результаты гонок** — итоговая классификация
- **ICS-файл** для импорта в календарь iPhone
- **Автоматическое обновление** через GitHub Actions каждые 30 минут
- **Бесплатно** — использует [Jolpica F1 API](https://github.com/jolpica/jolpica-f1) (без API-ключа)

## Структура проекта

```
f1-calendar/
├── .github/
│   └── workflows/
│       ├── update-data.yml    # Автообновление данных каждые 30 минут
│       └── deploy.yml         # Публикация на GitHub Pages
├── data/
│   └── races.json              # Данные гонок (генерируется автоматически)
├── scripts/
│   └── update_f1_data.py      # Скрипт обновления данных
├── f1-calendar.ics            # ICS-календарь (генерируется автоматически)
├── index.html                 # Веб-сайт
└── README.md
```

## Как работает автоматизация

1. GitHub Actions запускается каждые 30 минут
2. Скрипт обращается к Jolpica F1 API (бесплатно, без ключа)
3. Получает актуальные зачёты пилотов и команд
4. Получает результаты квалификаций и гонок для прошедших этапов
5. Обновляет `f1-calendar.ics` и `data/races.json`
6. Изменения коммитятся в репозиторий
7. GitHub Pages автоматически публикует обновлённый сайт

## Настройка (подробная инструкция)

### 1. Создайте аккаунт на GitHub

Если у вас нет аккаунта:
1. Откройте [github.com](https://github.com)
2. Нажмите **Sign up**
3. Заполните данные и подтвердите email

### 2. Создайте репозиторий

1. Нажмите **+** в правом верхнем углу → **New repository**
2. Заполните:
   - **Repository name**: `f1-calendar`
   - **Description**: `Автоматизированный календарь Формулы 1 2026`
   - **Visibility**: Public
   - **Add README**: No (файлы загрузятся позже)
3. Нажмите **Create repository**

### 3. Загрузите файлы проекта

**Способ 1 — через веб-интерфейс:**

1. Скачайте ZIP-архив с файлами проекта
2. Распакуйте его
3. В репозитории нажмите **Add file → Upload files**
4. Перетащите все файлы (включая папку `.github`)
5. Нажмите **Commit changes**

**Способ 2 — через командную строку:**

```bash
git clone https://github.com/ВАШ_ЛОГИН/f1-calendar.git
# Скопируйте файлы в папку
cd f1-calendar
git add -A
git commit -m "Initial commit"
git push
```

### 4. Включите GitHub Pages

1. Откройте **Settings** репозитория
2. В левом меню выберите **Pages**
3. В разделе **Source** выберите **GitHub Actions**
4. Закройте настройки

### 5. Включите GitHub Actions

1. Откройте вкладку **Actions** в репозитории
2. Если появится предупреждение, нажмите **I understand my workflows, go ahead and enable them**
3. Вы увидите два workflow: `Update F1 Data` и `Deploy to GitHub Pages`

### 6. Запустите первое обновление

1. В **Actions** выберите **Update F1 Data**
2. Нажмите **Run workflow** → **Run workflow**
3. Дождитесь завершения (1-2 минуты)
4. Затем запустится **Deploy to GitHub Pages**

### 7. Откройте сайт

После успешного деплоя сайт будет доступен по адресу:

```
https://ВАШ_ЛОГИН.github.io/f1-calendar/
```

### 8. Добавьте календарь на iPhone

**Способ 1 — импорт файла:**

1. Откройте сайт на iPhone
2. Нажмите **Скачать .ics**
3. В открывшемся окне нажмите **Добавить все**

**Способ 2 — подписка (автообновление):**

1. На iPhone откройте **Настройки → Календарь → Учётные записи → Добавить учётную запись → Другой → Подписка на календарь**
2. Введите URL:
   ```
   https://ВАШ_ЛОГИН.github.io/f1-calendar/f1-calendar.ics
   ```
3. Нажмите **Далее** → **Сохранить**

При подписке календарь будет автоматически обновляться при каждом обновлении ICS-файла.

## API

Проект использует **Jolpica F1 API** — бесплатный API без необходимости регистрации и API-ключа:

- Документация: [github.com/jolpica/jolpica-f1](https://github.com/jolpica/jolpica-f1)
- Базовый URL: `https://api.jolpi.ca/ergast/f1`
- Лимит: ~200 запросов в час (достаточно для обновления каждые 30 минут)
- Покрытие: расписания, результаты, квалификации, зачёты

## Технологии

- **GitHub Pages** — хостинг сайта
- **GitHub Actions** — автоматизация обновлений
- **Jolpica F1 API** — источник данных
- **ICS** — формат календаря для iPhone
- **HTML/CSS/JS** — фронтенд без фреймворков
