# F1 Календарь 2026

Полностью автоматизированный календарь Формулы 1 2026 для iPhone и веб-сайта.

## Возможности

- **23 этапа** — все сессии (FP1, FP2, FP3, Спринт-квалификация, Спринт, Квалификация, Гонка)
- **Время по МСК** (UTC+3)
- **Личный зачёт пилотов** — топ-23 пилота с очками
- **Командный зачёт** — все 11 команд с очками
- **Результаты квалификации** — стартовая решётка для прошедших гонок
- **Результаты гонок** — итоговая классификация
- **Live View** — вкладка с интерактивной картой трассы, позициями пилотов, пит-стопами, погодой, дирекцией гонки и радио-переговорами (данные [OpenF1](https://openf1.org))
- **ICS-файл** для импорта в календарь iPhone
- **Напоминания в ICS** — практики за 10 мин, спринт-квалификация за 20 мин, квалификация за 30 мин, гонка и спринт за час
- **Автоматическое обновление** через GitHub Actions каждые 30 минут
- **Бесплатно** — использует [Jolpica F1 API](https://github.com/jolpica/jolpica-f1) и [OpenF1](https://openf1.org) (без API-ключа)

## Как работает автоматизация

1. GitHub Actions запускается каждые 30 минут
2. Скрипт обращается к Jolpica F1 API (бесплатно, без ключа)
3. Получает актуальные зачёты пилотов и команд
4. Получает результаты квалификаций и гонок для прошедших этапов
5. Отдельно собирает данные Live View из OpenF1 (позиции, погода, пит-стопы, радио)
6. Обновляет `f1-calendar.ics`, `data/seasons/*.json` и `data/live/*`
7. Изменения коммитятся в репозиторий
8. GitHub Pages автоматически публикует обновлённый сайт

## Live View

Отдельная вкладка с телеметрией сессии: интерактивная карта трассы с позициями
пилотов, плей/пауза и перемотка, пит-стопы, погода (температура, ветер, дождь
с графиком), дирекция гонки и радио-переговоры с аудио.

**Важно про реальное время.** Бесплатный тариф OpenF1 отдаёт сессию только
через ~30 минут после её окончания, поэтому вкладка — это ретроспектива, а не
прямой эфир. Прямой эфир (WebSocket) доступен только на платном тарифе.
Интерфейс честно об этом предупреждает.

Почему данные собираются заранее, а не запрашиваются из браузера:

- лимит OpenF1 — 30 запросов в минуту на IP, и он общий для всех посетителей;
  при прямых запросах из браузера сайт быстро упрётся в лимит для всех;
- браузеру всё равно нужен JSON, а отдавать его может сам GitHub Pages;
- задержка бесплатного тарифа (~30 мин) совпадает с периодом обновления.

Контуры трасс не нарисованы вручную — они строятся из реальной телеметрии
OpenF1, поэтому работают для любой трассы автоматически.

Лицензия данных OpenF1 — CC BY-NC-SA 4.0, некоммерческое использование.
Ссылка на openf1.org в интерфейсе и футере оставлена.

## Реальное время (опционально)

Бесплатный тариф OpenF1 отдаёт сессию только через ~30 минут после финиша.
Живые данные F1 бесплатны, но браузер не может читать их напрямую: официальная
лента `livetiming.formula1.com` не отдаёт заголовки CORS, а GitHub Pages —
статика без постоянно работающего процесса.

Поэтому в `live-service/` лежит микросервис: он читает официальную ленту F1
по WebSocket и отдаёт JSON с открытым CORS.

Ключевой момент: сервис **не использует** `SignalRClient` из FastF1. Тот сначала
делает `POST .../signalrcore/negotiate`, а этот эндпоинт нестабилен — наблюдались
таймауты по 20 секунд, тогда как сам WebSocket отвечал `101 Switching Protocols`
за 0,4 с. Свой клиент (`livews.py`) открывает сокет напрямую и говорит на
SignalR-JSON сам, без negotiate.

Сокет постоянно висит в фоне и только накапливает последние значения; вся
история сессии в памяти не хранится. Замерено: **112 МБ рабочей памяти и почти
нулевая нагрузка CPU** — это влезает в бесплатный тариф 512 МБ.

Чтобы включить, пропишите адрес в атрибуте `<body>` файла `index.html`:

```html
<body data-live-service="https://ваш-сервис.example.com">
```

Пустое значение — работа только на статических данных. Если сервис недоступен,
вкладка Live View молча возвращается к ним.

Разместить можно бесплатно и без банковской карты на Railway или Render
(`Dockerfile` уже готов в корне репозитория). Fly.io не подойдёт — он требует
привязку карты.

Пошаговая инструкция — в [`live-service/DEPLOY.md`](live-service/DEPLOY.md).
Подробности и ограничения — в [`live-service/README.md`](live-service/README.md).

## Настройка (подробная инструкция)

### 1. Создайте аккаунт на GitHub

Если у вас нет аккаунта:
1. Откройте [github.com](https://github.com)
2. Нажмите **Sign up**
3. Заполните данные и подтвердите email

### 2. Создайте репозиторий

1. Нажмите **+** в правом верхнем углу → **New repository**
2. Заполните:
   - **Repository name**: `f1-calendar`
   - **Description**: `Автоматизированный календарь Формулы 1 2026`
   - **Visibility**: Public
   - **Add README**: No (файлы загрузятся позже)
3. Нажмите **Create repository**

### 3. Загрузите файлы проекта

**Способ 1 — через веб-интерфейс:**

1. Скачайте ZIP-архив с файлами проекта
2. Распакуйте его
3. В репозитории нажмите **Add file → Upload files**
4. Перетащите все файлы (включая папку `.github`)
5. Нажмите **Commit changes**

**Способ 2 — через командную строку:**

```bash
git clone https://github.com/ВАШ_ЛОГИН/f1-calendar.git
# Скопируйте файлы в папку
cd f1-calendar
git add -A
git commit -m "Initial commit"
git push
```

### 4. Включите GitHub Pages

1. Откройте **Settings** репозитория
2. В левом меню выберите **Pages**
3. В разделе **Source** выберите **GitHub Actions**
4. Закройте настройки

### 5. Включите GitHub Actions

1. Откройте вкладку **Actions** в репозитории
2. Если появится предупреждение, нажмите **I understand my workflows, go ahead and enable them**
3. Вы увидите два workflow: `Update F1 Data` и `Deploy to GitHub Pages`

### 6. Запустите первое обновление

1. В **Actions** выберите **Update F1 Data**
2. Нажмите **Run workflow** → **Run workflow**
3. Дождитесь завершения (1-2 минуты)
4. Затем запустится **Deploy to GitHub Pages**

### 7. Откройте сайт

После успешного деплоя сайт будет доступен по адресу:

```
https://ВАШ_ЛОГИН.github.io/f1-calendar/
```

### 8. Добавьте календарь на iPhone

**Способ 1 — импорт файла:**

1. Откройте сайт на iPhone
2. Нажмите **Скачать .ics**
3. В открывшемся окне нажмите **Добавить все**

**Способ 2 — подписка (автообновление):**

1. На iPhone откройте **Настройки → Календарь → Учётные записи → Добавить учётную запись → Другой → Подписка на календарь**
2. Введите URL:
   ```
   https://ВАШ_ЛОГИН.github.io/f1-calendar/f1-calendar.ics
   ```
3. Нажмите **Далее** → **Сохранить**

При подписке календарь будет автоматически обновляться при каждом обновлении ICS-файла.

## API

Проект использует два бесплатных источника, оба без API-ключа:

**Jolpica F1 API** — календарь, результаты, квалификации, зачёты:

- Документация: [github.com/jolpica/jolpica-f1](https://github.com/jolpica/jolpica-f1)
- Базовый URL: `https://api.jolpi.ca/ergast/f1`

**OpenF1** — телеметрия для вкладки Live View:

- Сайт: [openf1.org](https://openf1.org), документация: [github.com/br-g/openf1](https://github.com/br-g/openf1)
- Базовый URL: `https://api.openf1.org/v1`
- Бесплатный тариф: все 18 эндпоинтов, исторические данные с 2023 года,
  3 запроса/с и 30 запросов/мин, CORS открыт для браузеров
- Используются: `sessions`, `drivers`, `location`, `pit`, `weather`,
  `team_radio`, `race_control`, `laps`
- Недоступны на бесплатном тарифе: live-данные в реальном времени
  (REST/MQTT/WebSocket — от €9.90/мес), `position`, `stint`
- Лицензия: CC BY-NC-SA 4.0 — только некоммерческое использование

## Технологии

- **GitHub Pages** — хостинг сайта
- **GitHub Actions** — автоматизация обновлений
- **Jolpica F1 API** — календарь, результаты и зачёты
- **OpenF1** — телеметрия для Live View
- **ICS** (RFC 5545) — формат календаря для iPhone, строки складываются по 75 октетов
- **HTML/CSS/JS** — фронтенд без фреймворков, SVG-карта трассы нативно
